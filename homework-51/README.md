### Project

In this project I create a game-app that called "Memory Card". The main sence is to remember the positions of the opened icons and find all pairs.

This app includes:
- 4×4 card field that contain 8 pair of cards
- Score, moves, and timer information in top section
- 2 card clicks = 1 move
- +10 score when user correctly matched pair
- User get game over after 20 seconds of inactivity
- Restart button to start a new game session

### Libraries
I use React Icons for the icons in cards, React Toastify for notifications, React Idle Timer for detecting user activity.

Some of the game logic was developed and finish with AI help.
