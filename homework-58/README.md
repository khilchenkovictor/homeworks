generateHash(input) - Функція, яка приймає рядок, хешує його алгоритмом SHA-256 і повертає хеш у шістнадцятковому форматі.

generatePasswordHash(
    password, 
    salt, 
    iterations = 10000, 
    keylen = 64, 
    digest = 'sha512') - Функція, яка приймає пароль і сіль для ускладнення хешу, а також дефолтні значення (кількість ітерацій хешування, довжину ключа і алгоритм хешування). Генерує хеш через pbkdf2Sync з crypto і повертає його у шістнадцятковому форматі.

verifyPassword(
  inputPassword,
  storedHash,
  salt,
  iterations = 10000,
  keylen = 64,
  digest = 'sha512',
) - Функція, яка приймає рядок пароля, збережений хеш, сіль для ускладнення хешу, а також дефолтні значення (кількість ітерацій хешування, довжину ключа і алгоритм хешування). Повертає true і лог "Пароль співпадає", якщо хеш введеного пароля співпадає зі збереженим хешем, в іншому випадку повертає false і лог "Пароль не співпадає".
